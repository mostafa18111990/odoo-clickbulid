ديمو المطاعم السعودي — Odoo Enterprise
=======================================

الغرض
-----

ينشئ هذا الموديول قاعدة عرض تجريبية مترابطة لمطعم سعودي باسم
«مطاعم مذاق نجد». جميع الأسماء والأرقام والعناوين وبيانات الاتصال
المضافة بواسطة الموديول تجريبية وغير صالحة للاستخدام القانوني.

سيناريو العرض المقترح (20–30 دقيقة)
-----------------------------------

1. افتح المشتريات واعرض أمر شراء المواد الخام وفاتورة المورد وسدادها.
2. افتح المخزون واعرض الدفعات وتواريخ الصلاحية ومواقع التبريد والتجميد
   واستراتيجية FEFO.
3. افتح التصنيع واعرض وصفة متعددة المستويات، ثم أمر إنتاج الأرز
   والدجاج المتبل وكبسة الدجاج.
4. افتح نقطة البيع واعرض صالات فرعي الرياض والطاولات والطلبات وضريبة 15%.
5. افتح تطبيق «إدارة المطعم» واعرض الطلبات حسب القناة والفرع والمنتج.
6. اعرض تسويات هنقرستيشن وجاهز ونون فود، بما في ذلك التسوية ذات الفارق
   المتعمد لشرح المطابقة.
7. اعرض الهدر وقوائم فتح وإغلاق الفرع وسلامة الغذاء.
8. اعرض التحليل المحاسبي لربحية الفروع والقنوات والعمولات.

حدود التكامل
------------

بيانات منصات التوصيل في الديمو محاكاة داخلية آمنة. الربط الحي مع
هنقرستيشن أو جاهز أو نون فود يحتاج وثائق API رسمية، وبيانات اعتماد
منصة، وعناوين Webhook معتمدة. لا يحتوي الموديول على مفاتيح أو أسرار
ولا يدّعي توافر API عام لهذه المنصات.

العودة
------

لا يعدّل الموديول ملفات Odoo الأساسية. يمكن تعطيله من التطبيقات،
وتستعاد قاعدة الديمو من نسخة PostgreSQL والـFilestore المطابقة لها.
